    Open a trace to review it

    Choose Open trace or results… or drop a file anywhere on this page. Record a trace with:

    zli compress FILE -p PROFILE -o FILE.zl --trace FILE.cbor

    The CBOR file and the DOT text zli prints both work, gzipped or not. A .bench.json file from codec_reviewer.py --bench-json opens as a page of ratio-vs-speed results. Files are read by the codec_reviewer.py process serving this page.

    Pipelines

    Pick a pipeline to draw it. Boxes are codecs, left to right in the order they ran. A line's thickness is what that stream costs in compressed bytes; "writes" is what a codec puts straight into the frame. Pipelines that ran the same way are drawn once, with sizes summed over their runs.

    Codec census

    Generated by tools/codec_reviewer. A stream's compressed size includes everything downstream of it, and a merge's cost is split evenly across its inputs, as the trace records them.
